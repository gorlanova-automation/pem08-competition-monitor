PEm08. Анализатор публичных лендингов платформ автоматизации
Елена Горланова, 28.10.2026

Ниша: платформы автоматизации. Выбраны n8n, Make, Zapier. В data — настоящие скриншоты и короткие текстовые извлечения, URL и время съёмки. Анализируется материал первых экранов, а не объективное качество продуктов.

Основа — https://github.com/Toxap/pem08 . Доработаны FastAPI, сервис ProxyAPI, Pydantic-схемы, веб- и PyQt6-интерфейсы. Добавлены design_score 0–10, animation_potential и evidence_limitations. По тексту design_score=null. Оценка изображения субъективна, идея анимации — предложение для нашей страницы, не вывод о реальной анимации конкурента.

Протестированы /analyzetext и /analyzeimage на трёх источниках: шесть успешных реальных API-запросов. /parsedemo по сохранённому снимку n8n тоже успешен, результат попадает в историю. Финальный JSON — evidence/live_tests.json. По умолчанию parser_mode=capture: данные собраны через разрешённый Chrome, затем анализируются снимки. Selenium-код сохранён для самостоятельного запуска, но живой Selenium-сбор в этой работе НЕ проверялся. Работа внутри Cursor также не заявляется: он установлен и авторизован, код доработан через Codex из-за сбоя управления окном.

Исправления по проверкам: cookie-окно перекрывало Make — выполнен новый снимок после выбора только необходимых cookie; JPEG был ошибочно назван PNG — исправлены имя и MIME без изменения пикселей; из логов убраны фрагменты ключа; строки модели экранируются перед выводом HTML; добавлены проверка схемы, размера/формата изображения и ограничение URL. Пять локальных проверок прошли.

Первая desktop-сборка не загрузила QtWidgets. После закрепления PyQt6 6.7.1 и Qt 6.7.3 пересобран competitionmonitor.exe. Проверка бинарного файла завершилась кодом 0: компоненты Qt созданы, backend healthy=true, история доступна. Это проверка запуска вне экрана, не полный ручной прогон GUI; скриншот окна desktop не подделывался. Реальные скриншоты относятся к веб-интерфейсу.

В публичный GitHub идут исходники, материалы и безопасные результаты, без ключей, .env, локальных вспомогательных запусков, virtualenv и файлов сборки. Исполняемый файл прикладывается отдельно к ДЗ. Для desktop нужен запущенный локальный backend. README содержит команды запуска, ограничения и происхождение основы.
